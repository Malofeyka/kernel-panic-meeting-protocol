# Baseline Specification: Web UI & Visual Review Editor

## Overview
Веб-интерфейс обеспечивает взаимодействие ответственного сотрудника секретариата с ИИ-агентом: первичную загрузку материалов, просмотр аналитики, визуальное редактирование проекта протокола, управление циклами правок (до 2 кругов повторной генерации) и скачивание готового файла.

## Requirements

### Requirement: UI-01 Multi-file Upload Interface
Система MUST предоставлять удобную форму загрузки файлов совещания:
- Аудиозапись (обязательно);
- Повестка (опционально);
- Список участников (опционально);
- Шаблон протокола (опционально);
- Предыдущие протоколы для проверки преемственности (опционально).

#### Scenario: Загрузка комплекта материалов
- **WHEN** пользователь перетаскивает файлы в форму и нажимает «Начать обработку»
- **THEN** система валидирует форматы файлов, сохраняет их в рабочую сессию и инициирует асинхронный пайплайн обработки.

### Requirement: UI-02 Visual Protocol Review Editor
Система MUST отображать промежуточный проект протокола в виде интерактивного редактора с возможностью редактирования:
- Текста решений;
- Формулировок поручений;
- Дат и дедлайнов (с проверкой формата);
- Ответственных исполнителей (с выпадающим списком из участников).

#### Scenario: Редактирование поручения
- **GIVEN** проект протокола с предупреждением об отсутствующем сроке
- **WHEN** секретарь кликает на поле даты и выбирает число, либо корректирует текст поручения
- **THEN** изменения мгновенно фиксируются в состоянии документа.

### Requirement: UI-03 Revision Loop Control (<= 2 Cycles)
Система MUST отслеживать количество кругов автоматической регенерации правок (не более 2 кругов).

#### Scenario: Превышение лимита кругов правок
- **GIVEN** выполнено 2 цикла запроса доработки через ИИ-агент
- **WHEN** пользователь запрашивает 3-й круг автоматической генерации
- **THEN** система блокирует вызов повторной генерации LLM и переключает интерфейс в режим эскалации (ручная точечная доработка без обращения к нейросети) с возможностью прямой выгрузки DOCX.

### Requirement: UI-04 Analytics & Discrepancies Panel
Система MUST визуально акцентировать внимание на рисках, пробелах (нет срока/исполнителя) и коллизиях с предыдущими протоколами рядом с редактируемым документом.
