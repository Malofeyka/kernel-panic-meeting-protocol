# Baseline Specification: Document Generation (Word / DOCX)

## Overview
Модуль генерации формирует официальный проект протокола в формате Microsoft Word (.docx) в строгом соответствии с шаблоном бланка Министерства образования Свердловской области.

## Requirements

### Requirement: DOC-01 Template Compliance
Система MUST подставлять извлечённые структурированные данные (шапка, дата, номер, председатель, секретарь, присутствующие, повестка, слушали, решили, поручения, подписи) в шаблон документа .docx.

#### Scenario: Генерация документа по шаблону
- **GIVEN** утверждённый шаблон `.docx` с метками/переменными и структурированный JSON протокола
- **WHEN** секретарь запрашивает выгрузку документа
- **THEN** система генерирует валидный файл `.docx`, сохраняя все стили, шрифты, отступы и таблицы, регламентированные шаблоном.

### Requirement: DOC-02 Custom Template Upload
Система SHOULD позволять загружать пользовательский шаблон протокола на случай изменения нормативных бланков Министерства.

#### Scenario: Использование обновленного шаблона
- **GIVEN** секретарь при создании сессии прикрепляет файл шаблона
- **WHEN** происходит экспорт протокола
- **THEN** генератор использует загруженный шаблон вместо дефолтного.
