# Baseline Specification: Security & Isolated Deployment

## Overview
Требования к защищённому контуру, изоляции данных и локальному развёртыванию на персональном компьютере сотрудника Министерства образования Свердловской области.

## Requirements

### Requirement: SEC-01 Zero External Cloud Exfiltration
Система MUST функционировать автономно без передачи аудиозаписей, стенограмм, протоколов или персональных данных во внешние публичные облака или сторонние непроверенные API.

#### Scenario: Проверка сетевой изоляции
- **GIVEN** рабочий процесс обработки совещания
- **WHEN** происходит выполнение STT, LLM-инференса и сборка DOCX
- **THEN** все сетевые вызовы происходят исключительно внутри локального хоста (localhost/unix socket) либо локальной сети защищённого контура Министерства.

### Requirement: SEC-02 Local Hardware Constraints & Packaging
Система SHOULD запускаться на отдельном персональном компьютере работника Министерства без необходимости сложной кластерной инфраструктуры (поддержка легковесного запуска или единого установочного сценария/скрипта).

#### Scenario: Установка и первый запуск
- **GIVEN** рабочее место под управлением Linux/Windows с установленными драйверами GPU/CPU
- **WHEN** администратор запускает установочный скрипт
- **THEN** система проверяет доступность весов локальной модели/STT и поднимает локальный веб-сервер.
